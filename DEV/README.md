# SXED — Technical & Engineering Documentation

This directory contains the engineering documentation, system architecture, and font creation pipeline for the **SXED** editor family (**S6ED**, **S61ED**, **S2ED**).

---

## Documents

- **[`ARCHITECTURE.md`](ARCHITECTURE.md)**  
  Core architectural design, memory map, variable-length line storage, mapper segment compaction, window and dropdown menu engine, dialog widgets, file browser, and MSX-DOS 2/Nextor disk error handling.

- **[`FONTS.md`](FONTS.md)**  
  Detailed specifications of the three font systems (6×8 on Screen 6, 8×8 on Screen 6, 4×8 on Screen 2), glyph layout rules, weight derivation algorithms, and step-by-step instructions for designing and compiling custom fonts.

---

For user manuals and keystroke references, see [`../DOC/MANUAL.md`](../DOC/MANUAL.md) and [`../DOC/SXED.TXT`](../DOC/SXED.TXT).
